# Hi, I'm Olisa

**I research how people think and work with AI, at the intersection of HCI and machine learning.**

**What I'm into**
- Human–AI interaction: when people check what an AI tells them, and when they stop
- Behavioural experiments that measure what people do, not just what they say
- Honest ML evaluation: no leakage, real baselines, and saying so when a model doesn't beat them

**Right now:** open to opportunities and collaborations in human–AI interaction, user experience, research, machine learning and data science.

**A few projects**
- [Cryptex](https://github.com/OlisaAsielue/cryptex-decoder-game): a puzzle game run as an online experiment. Does a story change how people persist and ask for help? ([play it](https://thriving-frangipane-f4337c.netlify.app/))
- [Research assistant](https://github.com/OlisaAsielue/research-assistant): a fully local RAG tool that answers from your own papers and shows which source each answer came from
- [Competitive balance in English football](https://github.com/OlisaAsielue/football-competitive-balance): 126 seasons and a calibrated match simulation to separate real divergence in club strength from rule-change artefacts
- [NBA player props model](https://github.com/OlisaAsielue/nba-player-props-model): XGBoost on a leak-proof feature store, beating a 10-game-average baseline on a held-out season
